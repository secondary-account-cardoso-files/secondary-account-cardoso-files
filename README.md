## 👨‍🎓 Sobre

Bem-vindo(a)! Este repositório reúne todos os projetos, exercícios e anotações desenvolvidos durante minha graduação em **Análise e Desenvolvimento de Sistemas** na <b>Unitri</b>. Aqui você encontra minha evolução acadêmica, experiências práticas e aprendizados compartilhados.
